# AI BOM Engine — Implementation Plan (Phase 0 → 3)

> Concrete, file-level build plan. Decisions locked (see `AI_BOM_PRODUCT_PLAN.md` §15):
> **Python · typed YAML rules · AppSec CI gate first · CycloneDX 1.7 ML-BOM.**
>
> The critical path for "AppSec CI gate" is: accurate model discovery → used/listed → **delta
> (base-ref)** → **policy/gate** → **SARIF + PR comment** → benchmark gate. Call-site finding is
> the single highest-value detection upgrade because it turns "this PR added a model" from a guess
> into a provable, blockable fact.

---

## 0. Guiding rules (carried from vet)

1. **One report stream, many sinks.** Every format is a projection of one versioned record stream.
2. **Closed enums, validated at runtime.** Invalid values → diagnostic, never a crash.
3. **Fail-open for data, fail-closed for policy.** A broken enrichment warns; a broken rule blocks.
4. **Evidence everywhere.** No claim without file/line/snippet; confidence is explicit.
5. **Local-first, offline-capable.** No source leaves the machine.
6. **The benchmark is a gate.** Recall/precision must not regress below round-3 (79% / 99%).
7. **Every bug fix ships a regression case** in the FP/evasion corpus.

## 2. Data model (concrete, locked)

```python
# aibom_engine/report/model.py
from __future__ import annotations
from dataclasses import dataclass, field, asdict
from typing import Literal, Optional

Kind        = Literal["model","provider","framework","agent","mcp","tool","vector_db",
                     "dataset","guardrail","service","secret","other"]
Use         = Literal["live","comment","message","text","docs","test","data","output","example"]
Tier        = Literal["declared","inferred","rejected"]
Role        = Literal["used","listed"]
Confidence  = Literal["high","medium","low"]
Change      = Literal["","added","modified","removed","unchanged"]
Severity    = Literal["critical","high","medium","low","info"]

@dataclass
class Evidence:
    file: str
    line: int
    col: int = -1
    use: Use = "live"
    snippet: str = ""
    via: str = ""          # "identifier:GPT_4_O" | "callsite:client.chat.completions.create" | ""
    category: str = ""

@dataclass
class Model:
    id: str                # canonical "openai/gpt-4o"
    name: str
    provider: str
    kind: str = "model"
    mode: str = ""         # chat|embedding|image|audio|code|rerank|...
    version: str = ""
    aliases: list[str] = field(default_factory=list)
    role: Role = "used"
    tier: Tier = "declared"
    confidence: Confidence = "medium"
    listed_reason: str = ""            # "model-picker table" | "token-limit table" | "catalog"
    ambiguous: list[str] = field(default_factory=list)  # candidate canonical ids
    found_by: list[str] = field(default_factory=list)
    evidence: list[Evidence] = field(default_factory=list)
    places: dict[str, int] = field(default_factory=dict)
    change: Change = ""
    # enrichment (filled by enrich.py):
    status: str = ""                   # active|deprecated|retired|limited|unknown
    modality: list[str] = field(default_factory=list)
    context_window: int = 0
    cost: dict = field(default_factory=dict)
    license: str = ""
    data_residency: list[str] = field(default_factory=list)
    training_data_unknown: bool = True
    self_hostable: bool = False

@dataclass
class Occurrence:
    file: str; line: int; column: int = 0
    language: str = ""; callee: str = ""

@dataclass
class Capability:                     # Layer 1
    id: str; description: str = ""
    vendor: str = ""; product: str = ""; service: str = ""
    tags: list[str] = field(default_factory=list)
    occurrences: list[Occurrence] = field(default_factory=list)
    change: Change = ""

@dataclass
class Agent:                          # Layer 3 (Phase 4)
    id: str; name: str; framework: str = ""
    models: list[str] = field(default_factory=list)
    tools: list[str] = field(default_factory=list)
    vector_stores: list[str] = field(default_factory=list)
    prompt_files: list[str] = field(default_factory=list)
    change: Change = ""

@dataclass
class PolicyFinding:
    id: str; control_id: str; family: str
    severity: Severity; confidence: Confidence = "high"
    subject: str = ""                 # model/capability/agent id
    locus: dict = field(default_factory=dict)
    change: Change = ""
    title: str = ""; description: str = ""
    evidence: list[dict] = field(default_factory=list)
    remediation: dict = field(default_factory=dict)
    suppression: Optional[dict] = None
    gate: Optional[dict] = None

@dataclass
class Diagnostic:
    level: Literal["warning","error"]; code: str; component: str
    message: str; count: int = 1; change: Change = ""

@dataclass
class Header:
    schema_version: str; tool: dict; scan: dict
    finders: list[str]; controls: list[dict]

@dataclass
class Trailer:
    summary: dict; gate: dict; record_count: int; finished_at: str
```

Closed enums are validated centrally (`report/schema.py` raises on unknown values); every sink
relies on that invariant.

## 4. Staged engine (`pipeline.py`)

```python
@dataclass
class ScanOptions:
    target: str; base_ref: str = ""
    policy: str = ""; fail_on: str = ""
    reports: list[tuple[str,str]] = field(default_factory=list)
    exclude: list[str] = field(default_factory=list)
    max_seconds: int = 120
    strict: bool = False; resume: bool = False; fresh: bool = False
    no_cache: bool = False

def run(opts) -> Result:
    artifacts = source.artifacts(opts.target)          # 1..n artifacts
    scan = state.open_or_continue(opts, artifacts[0])  # resume if compatible
    extract(scan, artifacts)                           # triage + manifests (Layer 1 seeds)
    find(scan)                                         # dictionary/context/shapes/callsites/capability
    merge(scan)                                        # canonicalize + aliases + dedupe → Models
    verify(scan)                                       # use/tier/role/confidence/ambiguous
    enrich(scan)                                       # KB metadata (offline)
    evaluate(scan)                                     # built-in controls → findings
    finalize(scan)                                     # policy + gate → trailer
    write(scan, opts.reports)                          # sinks
    return Result(scan, exit_code)
```

Failure semantics: each stage records diagnostics instead of aborting where safe; `--strict`
promotes any diagnostic to exit 3; a finder exception is caught and recorded (current behavior,
kept and made a Diagnostic).

## 5. The call-site finder (highest-value new code)

`finders/callsites.py` extracts `model=` values from real client calls, producing `Finding` records
with `note="callsite:<fn>"` and `snippet` = the call line, category from triage, `col` = model
string position.

Mechanism (per language, AST-first with regex fallback):

| Language | Primary parse | Patterns |
|---|---|---|
| Python | `ast` (stdlib) | `Model=` kwarg to known client methods; `model="..."` kwarg; `GenerativeModel("...")`; `Literal[...]` catalogs |
| JavaScript/TS | `esprima`/`tree-sitter` (dep) or regex | `model:"..."`, `model:` in client `.create/.chat` calls |
| YAML/JSON | structural walk | keys `model`, `model_id`, `modelId`, `model_name` under provider blocks |
| Generic | import/namespace resolution | `<sdk>.<verb>(model=...)` with SDK from import |

Seed a **client catalog** mapping SDK → method + arg name:

```jsonc
// knowledge/clients.json
[
  {"sdk":"openai","methods":["chat.completions.create","responses.create","embeddings.create"],"arg":"model"},
  {"sdk":"anthropic","methods":["messages.create"],"arg":"model"},
  {"sdk":"google.generativeai","ctor":"GenerativeModel","arg":null,"positional":0},
  {"sdk":"boto3.client('bedrock-runtime')","methods":["invoke_model"],"arg":"modelId"},
  {"sdk":"ollama","methods":["chat","generate"],"arg":"model"},
  {"sdk":"requests","hint":"/v1/chat/completions","json_path":"model"}
]
```

Extracted names become `Finding(kind="model", name="gpt-4o", note="callsite:...")` and merge into the
same Model stream. This finder adds **used** evidence with a call-site — the strongest tier.

## 7. Delta / PR mode (prerequisite: git history)

We must `git init` the repo, and the tool needs to read a base ref. Implementation:

1. **Git backend** (`state/gitbase.py`):
   - `subprocess git` primary (CI + dev machines have it); `dulwich` (pure Python) fallback.
   - `ls_tree(ref)` → `{path: (mode, blob_sha, size)}`; `read_blob(sha)` → bytes.
2. **Change detection** (vet's approach, simplified):
   - For each file, if head blob hash == base blob hash → unchanged, reuse head results.
   - Else run finders on the file, and compare emitted entities to the base's.
3. **Entity diff** (in `merge.py`/`delta.py`):
   - model added = in head, not base (by canonical id).
   - removed = in base, not head.
   - modified = same id, changed provider/version/role.
   - capability/agent added/removed analogously.
4. **Finding filtering**: in PR mode keep only findings whose subject has `change in
   (added, modified)`.
5. **Base policy**: CI reads `policy.yml` from the base commit, so a PR can't disable its own gate.

## 8. Policy: typed YAML + evaluator + gate

### 8.1 Schema

```yaml
# policy/starter.yml  (generated by `aibom policy init`)
version: 1
providers:
  approved: [openai, azure-openai, anthropic]
  denied: []
models:
  denied: []
  deprecated: warn        # fail | warn | ignore
  data_residency: [us, eu]
  require_license: false
rules:
  - id: no-unapproved-provider
    scope: model
    action: fail
    severity: high
    match:
      provider: {not_in: "providers.approved"}
    remediation: "Approve the provider in .aibom/policy.yml, or migrate off it."
suppressions:
  - subject: "model:openai/gpt-3.5-turbo"
    reason: "Legacy feature, EOL next quarter"
    expires: "2026-03-01"
```

### 8.2 Evaluator

- `loader.py` parses and validates (unknown key → usage error; bad enum → usage error).
- `evaluator.py` walks entities in order; for each rule, resolves `match` with operators
  `equals, in, not_in, contains, glob, gt, lt`.
- **Built-in controls** (`controls.py`) are expressed as the same rules internally, so `policy`
  and `--fail-on` share one evaluator.
- Broken rule (resolution error) → fail-closed, recorded as `gate.broken`.

### 8.3 Gate

```python
class Gate:
    fail: bool; rules: list[str]; finding_ids: list[str]; broken: list[str]
    def result(self) -> dict:  # outcome pass|fail|none
```

Exit codes: 0 (pass/none) · 1 (gate fail) · 2 (usage) · 3 (strict/runtime) · 130 (signal).

## 9. State & cache

`state/store.py` uses stdlib `sqlite3`:

```
~/.aibom/
  index.db        : scans(target_key, options_hash, status, gate, packages, models, started_at, finished_at, size)
  scans/<id>.db   : artifacts(path,size,mtime,status), files, findings, models, capabilities, agents,

  kb/models.cache.json
```

- `open_or_continue`: resume if same target_key + options_hash + tool version and scan stopped.
- `report show last`: read a saved scan, re-run policy, re-render any sink without rescanning.
